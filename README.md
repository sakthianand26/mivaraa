# Mivaraa

A stylish coming soon page for Mivaraa.

## 🚀 Live Site

This repository contains a static coming soon page that can be deployed to GitHub Pages.

## 📁 Structure

- `/docs` - Contains the GitHub Pages site with the coming soon page

## 🌐 Deployment

This site is ready to be deployed via GitHub Pages:

1. Go to repository Settings → Pages
2. Select "Deploy from a branch"
3. Choose your branch and `/docs` folder
4. Save and your site will be live!

## 🎨 Features

- Beautiful gradient background
- Animated floating particles
- Responsive design for all devices
- Smooth animations and transitions
- Ready for custom domain configuration

## 📝 Custom Domain Setup

To point your custom domain to this GitHub Pages site:

1. Add your custom domain in GitHub Pages settings
2. Create a CNAME record with your DNS provider pointing to `<username>.github.io`
3. GitHub will automatically provision an SSL certificate

For more details, see the [docs/README.md](docs/README.md) file.
