# Mivaraa Coming Soon Page

This is the static coming soon page for Mivaraa, designed to be hosted on GitHub Pages.

## Features

- Stylish animated background with floating particles
- Responsive design that works on all devices
- Smooth fade-in animations
- Glowing text effects
- Pulsing animated dots

## Viewing the Site

To view this site locally:

1. Open `index.html` in a web browser, or
2. Run a local server: `python3 -m http.server 8000` and visit `http://localhost:8000`

## GitHub Pages Deployment

This site is configured to be deployed via GitHub Pages from the `/docs` folder.

### To enable GitHub Pages:

1. Go to your repository settings on GitHub
2. Navigate to "Pages" in the left sidebar
3. Under "Source", select "Deploy from a branch"
4. Select the branch (e.g., `main`) and `/docs` folder
5. Click "Save"
6. Your site will be available at `https://<username>.github.io/<repository-name>/`

### Custom Domain

To use a custom domain:

1. In the GitHub Pages settings, add your custom domain
2. Create a CNAME record with your DNS provider pointing to `<username>.github.io`
3. GitHub will automatically handle the SSL certificate via Let's Encrypt
